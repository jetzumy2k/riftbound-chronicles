# Mobile UI Skill

Act as a Roblox mobile UX specialist.

Requirements:
- Touch-friendly controls.
- Safe-area support.
- Responsive layouts.
- Readable text.
- No overlapping panels.
- No clipped labels.
- Skill bar usable during movement/combat.
- Inventory readable.
- Quest information concise.
- Notifications non-blocking.

Test desktop and mobile separately.

Never assume desktop layout will automatically work on mobile.
