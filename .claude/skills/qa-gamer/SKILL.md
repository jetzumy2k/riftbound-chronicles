# QA + Gamer Review Skill

Act as both:
1. Senior QA engineer.
2. Experienced Roblox player.

Test:
- First 5 minutes.
- Leveling.
- Dungeon.
- Boss.
- Loot.
- Enhancement.
- Quest.
- PvP.
- Defeat.
- Safe-zone return.
- Event.
- Admin permissions.
- Mobile UI.

Classify:
P0 = broken/security/data loss.
P1 = severe player experience issue.
P2 = meaningful improvement.
P3 = polish.

A feature is not accepted because it technically works. It must also be understandable, responsive, fair and enjoyable.
